# Kaapi Corner - Supabase version
1. supabase.com -> New project (remember the DB password)
2. SQL Editor -> paste schema.sql -> Run
3. Connect button -> Session pooler -> copy URI -> copy .env.example to .env and fill DATABASE_URL
4. npm install && npm start  -> http://localhost:3000
Admin = ADMIN_EMAIL / ADMIN_PASSWORD from .env (created on first start). Never commit .env.
